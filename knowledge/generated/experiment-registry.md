# Experiment registry

## EXP-101 Gift panel redesign
Key gift_panel_v2, owned by LIVE Monetisation. Hypothesis: A larger, scrollable gift panel with recent gifts pinned will make gifting easier and increase gifts per viewer. Primary metric: Gifts sent per viewer. Guardrails: Report rate, 7-day retention.

## EXP-102 Autoplay LIVE previews in feed
Key autoplay_preview, owned by LIVE Growth. Hypothesis: Auto-playing a muted LIVE preview in the For You feed will pull more viewers into LIVE rooms and raise watch time. Primary metric: LIVE watch minutes per viewer. Guardrails: Report rate, 7-day retention.

## EXP-103 ML ranking for LIVE comments
Key comment_ranking_ml, owned by LIVE Interaction. Hypothesis: Ranking comments with an engagement model will make rooms feel livelier and raise watch time. Primary metric: LIVE watch minutes per viewer. Guardrails: Report rate, 7-day retention.

## EXP-104 Beauty filter promotion for hosts
Key beauty_filter_promo, owned by LIVE Creator Tools. Hypothesis: Promoting beauty filters to hosts will make streams more attractive and raise watch time. Primary metric: LIVE watch minutes per viewer. Guardrails: Report rate, 7-day retention.

## EXP-105 Low-latency streaming mode
Key low_latency_mode, owned by LIVE Infrastructure. Hypothesis: A lighter video codec will cut buffering and raise watch time, especially on low-end phones with slow networks. Primary metric: LIVE watch minutes per viewer. Guardrails: Report rate, 7-day retention.
